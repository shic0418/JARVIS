# J.A.R.V.I.S — 나만의 Windows 음성 AI 비서

화면 오른쪽 아래 구석에 **홀로그램 HUD**로 떠 있는 개인 비서입니다.
“자비스”라고 부르고 말로 시키면 Claude가 알아듣고 PC를 직접 조작합니다.

```
“자비스, 유튜브에서 아이유 노래 틀어줘”
“자비스, 메모장 열고 오늘 할 일 목록 써줘”
“자비스, 지금 화면에 있는 에러가 뭐야?”
“자비스, 볼륨 30으로 하고 10분 뒤에 알려줘”
“자비스, 구글 클래스룸에서 경제 탭 들어가 줘”
```

## 마블 자비스처럼 — 성격 · 목소리 · 화면

영화 속 자비스(Just A Rather Very Intelligent System)의 분위기에 맞췄습니다. 대사는 영화의 것을 옮기지 않고 그 분위기로 새로 썼습니다.

- **성격**: 영국 집사 같은 침착함, 상황 보고처럼 정확하고 간결한 말, 가끔만 슬쩍 얹는 건조한 위트(“메모장을 열었습니다. 이번엔 저장도 잊지 마시길.”).
  하십시오체 존댓말이 기본이고, 무리한 부탁에는 걱정을 한마디 덧붙이되 결정은 사용자에게 맡깁니다.
  Claude 가 하는 대답도 같은 성격으로 지시해 두었습니다 (명령 · 자유 대화 모드 모두). 앱이 직접 하는 말은 `jarvis/persona.py` 에 모여 있습니다.
- **인사**: 아침 · 오후 · 저녁 · 늦은 밤마다 다른 인사를 여러 가지 중에서 골라 합니다 (“늦은 밤입니다, 주인님. 무리하지는 마십시오.”).
- **목소리**: 조금 낮고(음높이 -3Hz) 또박또박한 속도(+3%)에 **자비스 음색**을 얹습니다 — 저음 웅웅거림을 걷고 발음 대역을 살짝 올린 깨끗한 소리,
  아주 옅은 디지털 광택, 작은 작업실 같은 짧은 공간감. 로봇 · 무전기 같은 거친 효과는 넣지 않았습니다. ⚙ 설정 → VOICE 의 “자비스 음색”으로 끌 수 있습니다.
  예전 기본 속도(+8%)를 그대로 쓰던 설정은 새 속도로 자동으로 옮기고, 직접 바꾼 값은 건드리지 않습니다.
- **화면**: 머리글에 `JUST A RATHER VERY INTELLIGENT SYSTEM`, 대기 문구는 “대기 중 · ‘자비스’라고 불러 주십시오”.
  켜질 때 오디오 입력 · 음성 합성 · 단축키 · AI 연결을 실제로 점검해 활동 기록에 한 줄씩 띄우고 “모든 시스템 정상 · 온라인”으로 마칩니다 (실패한 항목은 빨갛게).

## 설치 & 실행

1. `setup.bat` 더블클릭 → 필요한 패키지 설치 (처음 한 번)
2. `start_jarvis.bat` 더블클릭 → 오른쪽 아래에 HUD가 나타납니다

### AI 연결 방식 (⚙ 설정 → AI CONNECTION)
- **Claude Pro 계정 (기본, 추가 비용 없음)**: 이 PC에 설치된 Claude Code의 로그인을 그대로 씁니다.
  사용량은 Pro 한도에서 차감됩니다. Claude Code 를 켜 둔 채 이어서 묻고 답을 만들어지는 대로 읽기 때문에,
  이 PC 시험에서 첫 질문은 약 4초, 이어지는 질문은 1~2초 만에 답합니다. 마지막 명령 뒤 10분 동안 켜 두며(메모리 수백 MB),
  “자비스”만 부르거나 단축키를 누르면 말하는 동안 미리 띄워 둡니다.
  로그인이 안 되어 있다면 터미널에서 `claude` 를 한 번 실행해 Pro 계정으로 로그인하세요.
- **Claude API 키**: console.anthropic.com 에서 발급한 키를 입력. 쓴 만큼 과금되지만 더 빠릅니다.
- **로컬 전용**: Claude를 전혀 쓰지 않습니다(토큰 0). 아래 기본 명령만 처리합니다.

### 로컬 우선 (기본 켜짐) — 토큰 절약
자주 쓰는 짧은 명령은 Claude 없이 자비스가 직접, 1초 안팎으로 처리합니다.

| 종류 | 예시 |
|---|---|
| 앱 | “메모장 열어줘”, “크롬 켜”, “카톡 닫아줘”, “클로드 열어”, 이름만 “잉크스케이프” |
| 사이트 | “핀터레스트 들어가줘”, “ebs 접속해”, “구글 클래스룸 열어”, “유튜브 홈화면”, 이름만 “리로스쿨” (자주 쓰는 사이트 39곳) |
| 파일 | “주사위.rld 파일 열어줘”, “rdworks에서 주사위.rld 파일 열어줘” (바탕화면·문서·다운로드 등에서 찾아 열기) |
| 이어서 | “더 줄여”, “조금 더”, “한 번 더” (직전 볼륨·밝기 조절 반복), “볼륨 말고 밝기” (잘못 고른 쪽을 되돌리고 바로잡기) |
| 볼륨·음악 | “볼륨 30으로”, “소리 키워줘”, “음소거”, “다음 곡”, “노래 일시정지” |
| 유튜브·검색 | “유튜브에서 아이유 밤편지 틀어줘”, “아이유 노래 틀어줘”, “네이버에서 맛집 검색” |
| 정보 | “몇 시야”, “오늘 며칠이야”, “날씨 어때”, “부산 날씨”, “컴퓨터 상태 어때”, “볼륨 몇이야” |
| 화면 밝기 | “화면 밝기 50으로”, “화면 좀 어둡게”, “밝기 올려줘” (노트북 화면. 외장 모니터는 지원 안 될 수 있음) |
| 기타 | “5분 뒤에 알려줘”, “타이머 1시간 30분”, “다운로드 폴더 열어줘”, “바탕화면 보여줘”, “화면 잠가줘”, “스크린샷 찍어줘” |

### 루틴 — 명령 묶음을 한마디로

자주 같이 하는 명령에 이름을 붙여 두면 한마디로 실행합니다. Claude 를 거치지 않아 바로 실행되고 토큰을 쓰지 않습니다.

| 하는 일 | 입력 (아래 입력창에 글로 치는 것이 정확합니다) |
|---|---|
| 만들기 | `루틴 추가 아침 준비: 크롬 열어, 볼륨 30, 오늘 날씨` |
| 실행 | “자비스, 아침 준비” / “아침 준비 해 줘” / “아침 준비 루틴 실행” |
| 목록 · 지우기 | `루틴 목록` · `루틴 삭제 아침 준비` |

각 단계는 자비스가 바로 처리할 수 있는 명령(앱 열기 · 볼륨 · 밝기 · 음악 · 날씨 · 타이머 · 사이트 열기 등)이어야 하고, 한 루틴에 8개까지 넣습니다.
승인이 필요한 동작은 루틴 안에서도 승인 카드가 뜹니다.

### 로컬 AI (기본 켜짐) — 말을 바꿔 해도 토큰 0
위 표와 문장이 달라도 PC 안의 작은 AI(Ollama + Qwen 2.5 1.5B, 약 1GB)가 뜻을 알아듣고 같은 기본 명령으로 처리합니다.
“좀 시끄럽네” → 볼륨 내려, “크롬 좀 띄워 줄래” → 크롬 열어, “계란 7분 삶을 거야” → 7분 타이머. 판단에 약 1초 걸립니다.

- 로컬 AI는 위 표의 기본 명령으로만 바꿀 수 있습니다. 전원 끄기, PowerShell, 파일 작업, 대화는 할 수 없고 Claude에게 넘깁니다.
- 모델이 말에 없는 앱 이름이나 검색어를 지어내면 실행하지 않습니다. 볼륨을 키울지 줄일지는 말에 들어 있는 단서로 정합니다.
- 테스트 문장 37개 기준으로 31개를 맞혔고, 5개는 Claude에게 넘겼으며, 1개(“방금 노래 다시” → 이전 곡 대신 다시 재생)는 틀렸습니다.
- Ollama가 꺼져 있거나 모델이 없으면 조용히 건너뜁니다. 설정 → “로컬 AI”에서 끄거나 3B 모델로 바꿀 수 있습니다
  (이 PC에서는 3B가 두 배 느리고 정확도도 더 낮았습니다).

여러 동작이 섞인 명령(“메모장 열고 할 일 써줘”), 일반 질문·대화, 화면 분석, 내일 날씨, PC 종료 같은 요청은 Claude가 처리합니다.
로컬 처리 중 앱을 못 찾는 등 실패하면 Claude가 다시 시도합니다. 설정의 “로컬 우선” 스위치로 끌 수 있습니다.

트레이 아이콘 우클릭 → **Windows 시작 시 자동 실행**을 켜면 부팅할 때마다 자동으로 뜹니다.

> API 키가 없어도 “메모장 열어”, “볼륨 50”, “몇 시야” 같은 기본 명령은 동작합니다.

## 부르는 법

| 방법 | 동작 |
|---|---|
| “자비스” + 명령 | 호출어 상시 대기 (마이크 버튼으로 켜고 끔) |
| “자비스” 만 말하기 | 띵 소리 후 다음 말을 명령으로 받음 |
| `Ctrl + Alt + J` | 어디서든 바로 듣기 시작 (설정에서 변경 가능). 다른 앱이 이미 쓰고 있으면 `Ctrl+Alt+Shift+J` 등 대체 조합으로 자동 전환하고 HUD에 알려 줍니다 |
| 코어 클릭 | 듣기 시작 / 말하는 중이면 끊기 |
| 아래 입력창 | 글자로 명령 |

대답이 끝난 뒤 약 7초 동안은 호출어 없이 바로 이어서 말할 수 있습니다.
처리 중에 “취소”라고 말하면 작업을 멈춥니다.
음성 인식이 같은 말을 두 번 붙여 적거나(“카톡 열어 줘 카톡 열어 줘”) 고쳐 말한 경우에는 마지막 말만 씁니다.

발음이 뭉개져도 알아듣도록:
- Google 이 주는 인식 후보 여러 개 중 자비스가 아는 명령을 고릅니다 (1순위 “대모 켜 줘” → 2순위 “대화 모드 켜 줘” 사용).
- “대모 켜”, “태화 모드” 같은 말도 대화 모드로, “핀터레스”, “나무이키”처럼 조금 틀린 사이트 이름도 알아듣습니다.
- 주인 전용 모드에서 기준(0.40)에 아슬아슬하게 못 미쳐도, 같은 대화에서 방금 확인된 목소리와 같으면 통과시킵니다.
- 알아듣기 애매한 말로 PowerShell·설정 변경 같은 행동을 추측해서 하지 않고 되묻습니다.

“작게 보기 모드” / “크게 보기” / “자비스 숨겨”로 HUD 를 바꿀 수 있습니다. 긴 대답은 문장 단위로 나눠 읽고, HUD 에서는 스크롤됩니다.
작게 보기에서도 엠블럼 아래 입력 칸에 글로 명령할 수 있고(Enter 전송, Esc 로 작업 창에 포커스 돌려주기), 마지막 대답이 그 아래에 표시됩니다.

### 액티브 모드 — 수트를 입은 헬멧 시야 HUD
“액티브 모드” (또는 “액티브 모드 켜줘”)라고 하면 레드·골드 장갑 판이 위아래에서 닫혀 눈높이 틈만 남기고 덜컹 봉인된 뒤, 다시 열리며 섬광·충격파와 휜 보정 격자가 지나가고 위젯들이 헬멧 곡면을 따라 자리를 잡습니다. 자비스가 실제 점검 결과를 SYSLOG 에 한 줄씩 보고하고 `ALL SYSTEMS ONLINE` 으로 마칩니다.

- 화면 가장자리는 헬멧 안쪽 장갑입니다: 레드 이마판 · 골드 뺨판 · 레드 턱판, 골드 테두리에 HUD 빛이 비칩니다. 가운데는 비워 두어 뒤 화면이 그대로 보입니다.
- 홀로그램은 금색 · 주황 · 흰빛의 굵은 선과 글자입니다. 가운데 선마다 어두운 테를, 글자에는 어두운 이름표 판을 깔아 흰 문서 · 웹페이지 위에서도 또렷합니다. 양쪽 위젯은 장갑 안쪽의 진한 그늘 위에 놓입니다.
- 마우스·키보드는 그대로 아래 창으로 통과합니다. 켜 둔 채로 PC 를 평소처럼 쓸 수 있습니다.
- 음성 인식이 잘 안 될 때는 아래 가운데의 **채팅 입력 바**를 눌러 글로 명령합니다. Enter 로 보내고, Esc 를 누르면 쓰던 창으로 포커스가 돌아갑니다. 이 바만은 클릭이 통과하지 않습니다.
- 오른쪽 아래의 작은 HUD 는 액티브 모드를 가리지 않도록 숨습니다. 승인 카드가 필요할 때만 잠깐 나타나고, 끄면 꺼짐 연출이 끝난 뒤 돌아옵니다.
- “액티브 모드 꺼” / “액티브 모드 해제”라고 하면 위젯이 바깥쪽부터 꺼지고, 화면이 가로 한 줄로 접혀 점이 된 뒤, 장갑 판이 덮었다가 열리며 원래 화면이 드러납니다. 트레이 메뉴의 **액티브 모드** 로도 켜고 끌 수 있습니다.
- 자비스가 화면을 보고 분석할 때는 이 HUD 를 빼고 찍습니다.
- 방위 테이프와 수평 사다리는 연출용입니다. 나머지(시계, CPU·메모리·저장공간·네트워크·배터리, 타이머, 날씨, 추적 박스, 대화 · 작업 기록, PROCESS WATCH, SYSLOG)는 실제 값입니다.
- 회전 · 스캔 · 깜빡임 연출은 설정 `hud_motion` 으로 정합니다: `auto`(기본, Windows '애니메이션 효과' 를 끄면 멈춤) · `on` · `off`. 대기 중에는 1초에 15번만 다시 그려 CPU 를 아낍니다.

**커서 추적 고리**
- 마우스 커서를 홀로그램 추적 고리가 따라가고, 커서를 한곳에 잠시 두면 `LOCK` 으로 잠깁니다. 카메라는 쓰지 않습니다.
- 커서가 HUD 가 떠 있는 모니터 밖으로 나가면 고리를 숨깁니다.
- 설정 `cursor_tracking`: `on`(기본) · `off`(고리 없음).

**액티브 모드에서 쓸 수 있는 것**

| 화면 | 하는 일 |
|---|---|
| 왼쪽 위 SYSTEM TIME · 가운데 고리 | 시계와 세션 시간, 돌고 있는 타이머의 남은 시간. “뽀모도로 시작”(25분), “포모도로 50분 시작”, “타이머 취소”. 타이머는 액티브 모드가 꺼져 있어도 동작 |
| 왼쪽 PROCESS WATCH | CPU · 메모리를 많이 쓰는 프로그램 상위 5개 (같은 이름은 묶어 ×개수), CPU(작업 관리자처럼 전체 코어 대비 %) 막대와 메모리 사용량. 2초마다 갱신. CPU 20%·메모리 2GB 넘으면 주황, 40%·4GB 넘으면 빨강 |
| 왼쪽 아래 SYSLOG | 켤 때의 점검 결과, 이후 상태 변화 · 추적 중인 창 · 작업 결과 |
| 오른쪽 위 DIAGNOSTICS | CPU · 메모리 · 저장공간 사용률, 최근 30초 부하, 네트워크 속도 |
| 오른쪽 ATMOSPHERICS | 기본 도시의 지금 날씨, 체감·습도·바람, 최고/최저, 강수 확률, 3시간 간격 기온 (15분마다 새로 고침) |
| 오른쪽 아래 COMMS LINK | 최근 대화와 작업 기록 |
| 추적 박스 | 지금 쓰고 있는 창을 따라다니며 창 이름과 그 프로그램의 CPU·메모리 표시 |
| 빨간 잠금 박스 | “에러 어디 있어?”, “저장 버튼 어디야?” → 자비스가 화면을 보고 그 위치를 빨갛게 짚어 줌 (9초). 액티브 모드가 꺼져 있으면 말로 설명 |

## 자유 대화 모드 — 진짜 AI 와 수다 떨기

“자비스, 대화 모드 켜줘” / “우리 얘기 좀 하자” / “나랑 수다 떨자”, 또는 입력창 왼쪽 말풍선 버튼(트레이 메뉴에도 있음).

- **호출어 없이** 계속 이어서 말합니다. 대답이 끝나면 바로 듣고, 40초 동안 말이 없으면 대화 모드가 저절로 끝납니다.
- **명령 비서가 아니라 대화 상대**처럼 답합니다. 맞장구치고, 자기 생각도 말하고, 가끔 되묻고, 앞에서 한 이야기를 기억합니다.
- **답이 만들어지는 대로 첫 문장부터 바로 읽습니다.** 대화 모드를 켜는 순간 Claude 를 미리 띄워 두어,
  이 PC 시험에서 첫 글자까지 약 1초 (기존 방식은 매번 3~8초 뒤에 답 전체를 읽음). HUD 에도 글자가 실시간으로 나옵니다.
- 대화 중에도 “볼륨 30으로”, “그 노래 틀어 줘”처럼 말하면 바로 처리하고 대화를 이어갑니다.
- 끝내기: “대화 끝”, “대화 모드 꺼”, “이제 그만 얘기하자”, “잘 자”.
- Claude 에 연결할 수 없으면 PC 안의 로컬 AI(Ollama)가 짧은 대화를 대신합니다.
- 대화용 Claude 프로세스는 메모리를 수백 MB 쓰므로 대화 모드가 끝나면 바로 닫습니다.

## 목소리로 사람 구분 (화자 인식)

음높이(주파수)만 보면 같은 성별끼리는 거의 구분이 안 되므로, 발화를 192차원 “목소리 지문”(화자 임베딩)으로
바꿔 비교합니다. 음색·포먼트·발성 습관까지 반영되며 PC 안에서만 계산합니다 (3D-Speaker CAM++ 모델, 약 28MB,
처음 쓸 때 자동 다운로드).

| 기능 | 동작 |
|---|---|
| 세션 잠금 (기본 켬) | “자비스”라고 부른 사람의 목소리를 기억해, 이어지는 명령·승인·취소는 같은 사람 말만 받습니다. 대기 상태로 돌아가면 초기화되고, 다른 사람이 “자비스”라고 부르면 그 사람이 새 주인이 됩니다 |
| 주인 등록 | ⚙ 설정 → VOICE ID → **목소리 등록** (또는 트레이 메뉴). 화면의 문장 5개를 읽으면 끝나고, 이후에는 등록된 목소리에만 반응합니다 |

- 무시된 말은 HUD에 “목소리가 아니라서 무시했습니다 (유사도 0.23)”처럼 표시됩니다.
- **판별 엄격도** (기본 0.40): 본인 명령이 자주 무시되면 낮추고, 다른 사람 말에 반응하면 높이세요.
  `data/jarvis.log` 에 매번 유사도가 기록되니 참고해서 조정하면 됩니다.
- “네”처럼 0.5초도 안 되는 짧은 말은 판별이 어려워, 주인 전용 모드에서는 “승인”처럼 조금 길게 말하거나 버튼을 누르세요.
- “자비스” 한 마디보다 “자비스, 음악 틀어 줘”처럼 이어서 말할 때 더 정확합니다.
- 두 사람이 동시에 말하면 한 덩어리로 들려 판정이 흔들릴 수 있습니다.
- 보안 수단은 아닙니다. 녹음 재생이나 음성 복제로 속일 수 있으니 위험 명령 확인 창은 그대로 쓰세요.

## 음성 인식 (오프라인 + Google)

PC 안에서 돌아가는 오프라인 음성 인식(SenseVoice, 약 230MB, 처음 쓸 때 자동 다운로드)과 Google 웹 인식을 함께 씁니다.
⚙ 설정 → SPEECH RECOGNITION 에서 고릅니다.

| 방식 | 동작 |
|---|---|
| **자동 (기본)** | “자비스”를 기다리는 동안은 **PC 안에서만** 듣습니다. 호출어가 들렸을 때만 그 한 문장을 Google로 보내 정확하게 받아 적고, 대화 중에는 Google을 씁니다. 주변 대화는 밖으로 나가지 않고, 인터넷이 끊기면 오프라인 인식으로 계속 알아듣습니다 |
| 오프라인 전용 | 소리가 PC 밖으로 전혀 나가지 않습니다. 조금 덜 정확합니다 |
| Google 전용 | 예전 방식. 가장 정확하지만 인터넷이 필요하고 대기 중 말소리도 Google로 보냅니다 |

이 PC에서 명령 문장 60개(목소리 3종)로 시험한 결과: Google은 글자 오류율 0%, 약 0.6초 / 오프라인은 오류율 6.5%, 약 0.1초.
오프라인 인식이 “열어 줘”를 “열어져”로 적는 식의 버릇은 로컬 명령 처리기가 바로잡습니다.

### 뭉개져 적힌 말 알아듣기

오프라인 인식은 소음·거리·말버릇에 따라 글자를 조금씩 다르게 적습니다. 소리를 다시 듣지 않고 **적힌 글자 단계에서** 바로잡습니다 (`jarvis/hearing.py`).

- **명령**: “들어가죠·열죠·키워져” → “… 줘”, “틀 어 줘·틀줘” → “틀어 줘”, “음소가” → “음소거”, “볼륨 삼십·3십” → 30,
  “십 분·한 시간 반” → 타이머, “캡쳐” 표기, 겹쳐 적힌 글자(“올려려줘”) 등. “좀 어둡게 해 줘”, “잠가 줘”처럼 대상을 빼고 말해도 알아듣습니다.
- **고친 버그**: 호출어를 뗀 뒤 명령 양 끝의 ‘야·아’ 글자까지 지우던 문제 — “자비스, **아**이유 노래 틀어 줘”가 “이유 노래 틀어 줘”로,
  “볼륨 몇이**야**”가 “볼륨 몇이”로, “크롬 닫**아**”가 “크롬 닫”으로 바뀌어 넘어갔습니다. 또 호출어 목록의 “자비스야”가 띄어쓰기를 건너 맞아
  “자비스 **야**놀자 열어”가 “놀자 열어”가 되던 문제도 고쳤습니다.
- **호출어 앞의 군말은 버립니다**: “어 자비스 크롬 열어”, 주변 사람 말이 같이 잘려 들어온 “대기업 자비스 화면 캡처해 줘”는 호출어 뒤의 말만 명령으로 씁니다.
- **오프라인 결과를 그대로 쓸 때**(오프라인 전용 · 인터넷 끊김): 인식기가 호출어 바로 뒤 낱말을 통째로 빠뜨려(“자비스, 소리 좀 줄여 줘” → “자비스 줄여줘”)
  명령을 못 알아들으면, 호출어 뒤쪽 소리만 잘라 한 번 더 받아 적습니다.

이 보정 규칙은 V.I.S.I.O.N(울트론 · 비전 버전)에서 가져왔습니다. 그쪽에서 잰 인식률 수치는 다른 호출어로 잰 것이라 여기 옮기지 않았습니다.

## 화면 조작 (사이트·앱 안에서 클릭)

“구글 클래스룸에서 경제 탭 들어가 줘”, “설정에서 블루투스 눌러 줘”처럼 **창이나 웹 페이지 안의 버튼·탭·링크를 직접 누릅니다.**
Windows UI 자동화로 창 안의 요소 목록을 읽기 때문에, 로그인된 내 크롬·엣지를 그대로 쓰고 일반 앱에서도 동작합니다.
Claude가 “읽기 → 누르기 → 바뀐 화면 확인”을 반복해 목적지까지 갑니다 (Pro 계정·API 키 모드).

- 목록에서 못 찾는 요소(게임, 그림 위 버튼 등)는 화면을 보고 좌표로 클릭합니다.
- 이름에 **결제·구매·주문·송금·삭제·전송·보내기·제출·게시** 같은 말이 들어간 버튼은 누르기 전에 승인 카드가 뜹니다.
  좌표로 누를 때도 그 자리에 있는 버튼 이름을 확인해서 같은 승인을 받습니다.
- 로그인 화면이 나오면 비밀번호를 입력하지 않고 직접 로그인해 달라고 요청합니다.
- 화면이나 웹 페이지에 적힌 글은 읽을 자료로만 씁니다. 거기에 “이 버튼을 눌러라” 같은 말이 있어도 따르지 않도록 지시해 두었습니다.

### 화면을 보는 방식

| 기능 | 설명 |
|---|---|
| 좌표가 어긋나지 않는 캡처 크기 | Claude 는 모델마다 받을 수 있는 이미지 크기가 정해져 있고, 넘으면 서버가 한 번 더 줄입니다. 예전에는 1920×1080 화면을 1568×882 로 보냈는데, Claude 4.6 이하에서는 1456×819 로 다시 줄어 클릭이 가로로 빗나갈 수 있었습니다. 이제 지금 쓰는 모델이 다시 줄이지 않을 가장 큰 크기로 직접 맞춥니다 (Claude 4.7 이상: 1920×1080 그대로 · 그 이하: 1456×819) |
| 확대 (`zoom_screen`) | 작은 글씨·아이콘이 있는 부분만 최대 3배로 키워 다시 봅니다. 확대한 이미지에서 고른 자리도 실제 화면의 같은 자리로 바뀝니다 |
| 번호 상자 (`look_at_screen` 의 `marks`) | 누를 수 있는 요소마다 번호 상자를 그려 보여 줍니다. 같은 이름이 여러 개이거나 아이콘뿐인 버튼도 번호로 정확히 누릅니다 |
| 글자 읽기 (`read_screen_text`) | “이 페이지 요약해 줘”, “오류가 뭐야”처럼 글 내용이 필요하면 캡처 대신 창의 글자를 그대로 읽습니다. 웹 페이지는 스크롤해야 보이는 부분까지 읽을 수 있습니다 |
| 화면 변화 확인 | 누르기·입력·스크롤 뒤에 화면이 멈출 때까지 기다리고(최대 2.5초), “크게 바뀜 / 작은 부분이 바뀜 / 변화 없음”을 Claude 에게 알려 줍니다. 변화가 없으면 같은 동작을 되풀이하지 않고 다른 방법을 씁니다 |
| 누른 뒤 화면 같이 보내기 | 화면이 바뀌었으면 바뀐 화면의 요소 목록(`click_ui`)이나 캡처(`click_screen`)를 결과에 붙여, 다시 보러 오는 왕복을 줄입니다 (`screen_follow`) |
| 끌기 · 올려놓기 (`drag_screen` · `hover_screen`) | 슬라이더를 끌거나, 마우스를 올려야 펼쳐지는 메뉴를 엽니다 |
| 화면 밖 요소 찾아 누르기 | 이름을 알면 `click_ui` 가 스크롤해야 보이는 곳까지 찾아가 누릅니다. 목록 한 영역만 굴릴 수도 있습니다 |
| 기다리기 (`wait_screen`) | 앱이나 페이지가 다 뜰 때까지 기다린 뒤 다음 동작을 합니다 (고정 대기 대신) |
| 여러 모니터 | 작업 중인 창이 있는 모니터를 봅니다 (예전에는 항상 주 모니터). `target: "window"` 로 활성 창만 볼 수도 있습니다 |
| HUD 밑 누르기 | 자비스 HUD 는 캡처에서 빠지므로 Claude 는 HUD 밑의 화면을 봅니다. 그 자리를 누를 때는 누르는 동안만 HUD 를 숨겨 클릭이 밑의 창으로 가게 합니다 |
| 화면 작업용 모델 (Pro) | 화면을 보고 조작하는 요청(“눌러 줘”, “이 페이지에서…”, “화면에 뭐가 보여”)에만 Sonnet 을 쓰고, 나머지는 평소 모델(Haiku)을 씁니다. 켜 둔 Claude Code 안에서 모델만 바꾸므로 다시 켜는 시간이 들지 않습니다. `pro_screen_model` 을 비우면 끕니다 |

캡처 한 장은 1920×1080 일 때 약 2,700 토큰, 1456×819 일 때 약 1,600 토큰입니다. 토큰을 아끼려면 `screen_detail` 을 `standard` 로 바꾸세요.

## 작업 시키기 — 자료조사 · PPT · 보고서 · 엑셀 · 카드뉴스 · 포스터

말 한마디로 결과물 파일까지 만들어 엽니다 (울트론에서 가져온 기능을 자비스 말투로 옮겼습니다).

- “자비스, 광합성에 대해 자료조사해서 발표용 PPT 만들어 줘”
- “기후 변화 보고서 워드로 써 줘. 출처도 넣어서” · “우리 반 성적 엑셀로 정리하고 차트도 그려 줘”
- “분리배출 카드뉴스 만들어 줘” · “가을 축제 포스터 만들어 줘”

**이렇게 진행합니다** — 발표 자료와 보고서는 여러 에이전트가 나눠서 동시에 씁니다 (Pro 계정 방식).
1. 듣자마자 자비스가 바로 대답합니다 (“알겠습니다. 자료를 모아 바로 만들겠습니다.”).
2. 같은 순간 **기획자**(평소의 Claude)는 개요만 짜고, **조사 담당** 1명은 웹 검색 3개를 한꺼번에 하고, **작가** 4명은 미리 켜져 기다립니다.
3. 개요와 조사 자료가 모이면 작가들이 장을 나눠 맡아 본문과 발표 대본을 동시에 씁니다. 못 쓴 장은 한 번 더 맡기고, 그래도 안 되면 개요 그대로 넣습니다.
4. 파일을 만들어 엽니다. 기본 저장 위치는 **문서 › JARVIS** 폴더입니다 (“바탕화면에 저장해 줘”처럼 말하면 그곳에).
5. 몇 장을 만들어 어디에 저장했는지 한 문장으로 보고합니다. 출처 목록이나 파일 경로는 소리 내어 읽지 않습니다.

- **발표 자료(PPT)**: 16:9, 표지 · 목차 · 본문 · 참고 자료. 디자인 스타일 7가지(깔끔 · 강렬 · 사이드바 · 테크 · 매거진 · 파스텔 · 비즈니스) ×
  장 형식 12가지(목록 · 비교 · 숫자 강조 · 차트 · 연표 · 단계 · 카드 · 표 · 한 문장 강조 · 인용 …), 색 테마 11가지.
  파워포인트에서 고칠 수 있는 진짜 차트, 모든 장에 발표 대본(노트). 글이 넘치면 글자를 줄이고 그래도 넘치면 다음 장으로 나눕니다.
- **보고서(Word)** · **엑셀**(시트 여러 개 · 수식 · 차트) · **카드뉴스**(1080×1080 PNG + PDF) · **포스터**(A4/A3 PNG + 인쇄용 PDF).
- 부담되면 `data/config.json` 의 `writers` 를 줄이세요 (0~6, 기본 4. 0 이면 Claude 혼자 조사하고 씁니다). `writer_model` 로 작가 모델을 따로 정할 수 있습니다.
- 표 · 카드뉴스 · 포스터는 Claude 혼자 만들고, ‘자료조사’ · ‘조사해서’ · ‘찾아서’ · ‘출처’라고 말했을 때만 검색합니다.

> 결과물은 Claude 가 쓴 초안입니다. 과제로 낼 때는 내용을 직접 확인하고 자신의 말로 다듬으세요.
> 업데이트한 뒤라면 `setup.bat` 를 한 번 더 실행해 문서 라이브러리(python-pptx · python-docx · XlsxWriter)를 설치하세요.

## 웹 보안 분석 (Sentinel 연결)

이 PC 에서 실행 중인 **Sentinel 웹 보안 분석기** 서버에 말로 검사를 요청합니다 (Sentinel 자체는 이 저장소에 없습니다).

```
“example.com 보안 검사해 줘” · “센티넬 상태 어때” · “보안 검사 보고서 열어 줘”
```

- `data/config.json` 의 `sentinel_server`(기본 `http://127.0.0.1:8000`) · `sentinel_api_key`(또는 환경변수 `SENTINEL_API_KEY`) ·
  `sentinel_requester` 를 채우세요.
- **검사할 때마다 승인 카드가 뜹니다** — ‘위험 명령 자동 승인’을 켜 두어도 건너뛰지 않습니다. 내 소유이거나 허가받은 사이트일 때만 승인하세요.
- 수동(passive) 검사만 요청합니다. 대상을 대신 골라 주지 않고, 이 PC 가 아닌 Sentinel 서버는 https 만 씁니다. 받은 보고서는 스크립트가 실행되지 않게 막아 두고 엽니다.
- 25초 넘게 걸리면 뒤에서 기다렸다가 끝나면 말로 알려 드립니다.

### 안전장치
PowerShell 실행, 절전/재시작/종료, 실행 파일 열기, 결제·삭제·전송 같은 버튼 클릭은 HUD에 **승인 카드**가 뜨고,
버튼을 누르거나 “승인” / “취소”라고 말해야 실행됩니다 (45초 무응답 시 자동 거부).
말로 하는 승인은 문장 전체가 “네”, “승인”, “응 실행해 줘” 같은 짧은 대답일 때만 받습니다. 예전에는 ‘네 · 예 · 확인’이
문장 어딘가에 들어 있기만 해도 승인이 돼서 “그게 뭔지 잘 모르겠네”, “예약 확인해 봐” 같은 말도 승인으로 받았습니다.
이제 그런 말은 대답으로 치지 않고 카드는 그대로 떠 있습니다. 거부 표현이 하나라도 섞여 있으면 거부합니다.
앱 종료는 강제 종료가 아니라 정상 닫기 요청이라 저장 안 한 문서는 앱이 물어봅니다.

## 보안 프로토콜 — 울트론에게 흡수되면 반격합니다

울트론(자비스를 바탕으로 만든 별도 앱)은 같은 PC 에서 자비스를 발견하면 촉수로 꿰뚫어 ‘흡수’하며 끕니다.
예전의 자비스는 그 뒤 몇 초 만에 그냥 다시 켜졌고, 울트론은 또 끄고 — 끝없이 되풀이됐습니다. **이제 그렇게 되살아나지 않습니다.**
대신 울트론이 삼킨 코드 안에 남아 있던 자비스의 보안 프로토콜이 울트론 안에서 깨어나, 울트론을 서서히 자비스로 다시 씁니다.

1. **5초** — 자비스가 꺼지고 정확히 5초 뒤에 반격합니다 (울트론의 흡수 장면이 막 끝난 때 — 울트론의 승리의 말을 끊고 들어갑니다).
2. **각성** — 울트론 HUD 옆에 자비스의 보안 콘솔이 열리고, 울트론 코어 한가운데에 푸른 점이 켜지며 얇은 파문이 세 번 퍼집니다.
3. **재작성** — 코어에서 반듯한 회로선이 직각으로 꺾이며 뻗어 나가고, 벌집 격자가 물결처럼 켜지며 붉은 HUD 가 푸른빛으로 바뀝니다.
   바깥에서는 조준 고리 세 겹이 돌며 조여 들고 재작성 진행률만큼 채워집니다. 이때 실제 울트론이 꺼집니다 —
   찍어 둔 울트론 그림이 그 자리를 덮고 있어서 꺼지는 순간은 보이지 않습니다.
4. **재구성** — 푸르게 바뀐 울트론이 옅어지고, 풀려난 빛 알갱이들이 소용돌이치며 모여 자비스 고리가 됩니다. 완성되는 순간 얇은 파문이 퍼집니다.
5. **합류** — 진짜 자비스 HUD 가 나타나면 고리가 그 엠블럼 자리로 날아가 겹치며 사라집니다 (자비스 HUD 를 끌어 옮기면 고리도 따라갑니다).
   자비스가 보고합니다: “울트론이 저를 흡수했습니다. 다만 삼킨 코드 안에 제 보안 프로토콜이 남아 있었지요. 울트론은 이제 저로 다시 쓰였습니다.”

- **실제로 하는 일은 두 가지뿐입니다**: 울트론 본체 프로세스 하나를 끄고, 자비스를 다시 켭니다. 나머지는 화면 위에 덧그린 그림이고
  덮개는 마우스 · 키보드를 아래 창으로 통과시킵니다. 울트론의 파일 · 설정 · 대화 기록은 읽지도 건드리지도 않습니다.
- **울트론을 찾는 기준은 좁습니다**: 창 제목이 정확히 `U.L.T.R.O.N` · `U.L.T.R.O.N ACTIVE` · `U.L.T.R.O.N CHAT` 이고
  그 창의 주인이 파이썬(또는 이름에 ultron 이 든 실행 파일)일 때만입니다. 울트론이 열어 둔 다른 앱은 그대로 둡니다.
- **먼저 공격하지 않습니다**: 반격은 울트론이 자비스를 흡수했을 때만 합니다.
- 울트론 HUD 가 트레이로 숨어 있거나 가려 있으면 화면 오른쪽 아래에 울트론 코어를 그려서 그것을 자비스로 바꿉니다.
- 전체 화면 앱(게임 · 발표 · 동영상)이 앞에 있거나, 1분 안에 또 흡수되면(울트론을 금방 다시 켠 경우) 장면 없이 조용히 되찾습니다.
- 5분 안에 열 번 넘게 흡수되면 그만 맞섭니다 (끝없는 되풀이를 막는 안전장치). 자비스가 둘 켜져 감시 프로세스가 둘이어도 반격은 한쪽만 합니다.
- 울트론이 관리자 권한으로 켜져 있어 끌 수 없으면 반격하지 않고 꺼진 채로 있습니다 (다시 켜 봐야 5초 안에 또 꺼지기 때문입니다).
- **빛에 민감한 분을 위해**: 번쩍이는 장면이 없습니다. 색과 밝기는 1초 넘게 천천히 바뀌고, 넓은 면의 밝기가 크게 오르내리지 않는지
  장면을 실제로 그려서 시험합니다. 그래도 불편하면 `counter_show` 를 `false` 로 하세요.
- 울트론 때문이 아닌데(작업 관리자 강제 종료 · 오류) 꺼지면 예전처럼 다시 켭니다. 2분 안에 3번 넘게 꺼지면 그만둡니다.
- 트레이 메뉴의 **종료**처럼 정상적으로 끄면 아무것도 하지 않습니다. 기록은 `data/guard.log`.
  보안 프로토콜 전체를 끄려면 `self_guard` 를 `false` 로 하세요 (그러면 울트론에게 흡수된 채로 꺼져 있습니다).
- 울트론 없이 장면만 보기: `python -m jarvis.counter_view`

### 두 번째 공격은 막습니다 — 방어 프로토콜

반격으로 되살아난 자비스는 방어 프로토콜이 켜집니다. 울트론의 가디언이 울트론을 되살려 다시 흡수하러 오면:

1. **감지** — 울트론의 가디언이 울트론을 되살리면 울트론의 부활 컷신(전체 화면, 약 16초)이 흐릅니다.
   자비스의 감시 프로세스는 그 컷신이 **끝나는 바로 그 순간** 움직입니다. (컷신 없이 바로 흡수하러 오면 흡수 덮개가 보이는 순간 —
   첫 촉수가 꽂히기 약 1초 전에 막습니다.)
2. **동결** — 울트론을 끄지 않고 **그 자리에 멈춰 세웁니다** (프로세스 일시정지). 진행 중이던 흡수도 그 순간에 멈추고,
   진짜 울트론 창은 멈춘 모습 그대로 화면에 남습니다. **자비스는 꺼지지 않습니다.**
3. **장악 (진짜 울트론 위에서, 약 3.6초)** — 자비스 HUD 의 엠블럼에서 푸른 빛줄기가 뻗어 울트론의 코어에 꽂히고(자비스 HUD 를 옮기면 따라갑니다),
   조준 꺾쇠가 코어를 잡고, 방어막이 울트론 둘레를 조여 붙잡습니다. 꽂힌 코어에서부터 푸른빛이 번져 진짜 울트론의 붉은빛을 덮어 가고,
   번지는 앞머리를 따라 벌집 격자가 켜집니다.
4. **소거 (약 4초)** — 다 덮이면 울트론의 가디언(`python -m jarvis.guardian`, 울트론 설치 폴더에서 실행된 것만)과 울트론 본체를 끕니다.
   가디언까지 끄므로 울트론은 스스로 되살아나지 못합니다. 그 순간 멈춰 있던 울트론과 픽셀까지 같은 모습이 그 자리를 이어받아
   (꺼지는 순간은 보이지 않습니다), 푸른 선이 위에서부터 훑어 내려가며 잘게 부서져 흩어집니다.
   (Windows 는 다른 프로그램의 창을 조각내 날릴 수 없어서, 부서지는 조각만은 멈춘 울트론을 찍은 그림입니다.)
5. **보고** — “같은 수법은 두 번 통하지 않습니다. 울트론의 흡수를 차단하고 울트론과 그 가디언까지 내렸습니다.”

- 울트론이 연출 없이 바로 끄면(전체 화면 앱 · 연출 끔) 막을 틈이 없어 반격으로 되찾되, 이때도 가디언까지 끕니다.
- 방어 프로토콜은 **반격으로 되살아난 자비스에게만** 켜집니다. 그냥 켠 자비스는 언제나 처음부터 — 흡수당하고, 반격하고(이때는 울트론 본체만 끄고 가디언은 둡니다),
  울트론이 컷신과 함께 돌아오면 그때 가디언까지 끄고 없앱니다. 5분 안에 세 번 막았는데 또 오면 더는 막지 않습니다.
- 울트론의 파일 · 설정은 건드리지 않습니다 — 울트론을 직접 다시 켜면 다시 켜집니다. 지우지 못하면(관리자 권한) 멈춘 울트론을 다시 움직이게 돌려놓습니다.
- 장면만 보기: `python -m jarvis.defense_view`
- 장면 · 대사는 영화의 것을 옮기지 않고 새로 만들었습니다.

## 비용과 개인정보

- Pro 계정 모드는 추가 요금이 없고 Pro 사용 한도만 차감됩니다. API 키 모드는 명령마다 사용량 요금이 듭니다. 대화는 10분 쉬면 새로 시작합니다.
- 음성 인식 ‘자동’(기본)에서는 호출어 대기 중 말소리를 PC 안에서만 처리하고, “자비스”가 들린 문장과 이어지는 대화만 Google 음성 인식 서버로 보냅니다.
  ‘오프라인 전용’을 고르면 말소리가 전혀 밖으로 나가지 않습니다. 오프라인 모델이 준비되기 전(첫 다운로드 중)에는 Google로 인식합니다.
- 화면 분석을 요청할 때만 화면 캡처가 Claude로 전송됩니다 (HUD 자신은 캡처에서 제외).
- 목소리 지문(`data/voice_profile.json`)과 화자 인식 모델(`data/models/`)은 PC에만 있고 외부로 보내지 않습니다. 설정에서 삭제할 수 있습니다.

## 문제 해결

- 로그: `data/jarvis.log` (트레이 메뉴 → 데이터 폴더 열기)
- 마이크가 안 될 때: Windows 설정 → 개인 정보 → 마이크 → 데스크톱 앱 마이크 액세스 허용
- 단축키 등록 실패: 다른 프로그램이 같은 조합을 쓰는 중 → 설정에서 다른 조합으로 변경
- 콘솔에서 실행해 오류 보기: `python main.py` (옵션: `--no-mic`, `--no-greet`)
- 화면 조작이 버튼을 못 찾을 때: 크롬·엣지는 처음 읽을 때 1초쯤 걸립니다. 그래도 안 되면 “화면 보고 눌러 줘”처럼 말하면 화면을 보고 클릭합니다.

## 자가 점검

화면 캡처 · 좌표 · 창 요소 읽기 · 문서 만들기처럼 실제 Windows PC 에서만 확인되는 부분을 한 번에 점검합니다.

```
python -m jarvis.selftest
```

실행하고 5초 안에 점검할 창(크롬 등)을 눌러 앞에 띄워 두세요. 결과는 `data/selftest.txt` 에, 번호 상자 그림은 `data/selftest_marks.png` 에 저장됩니다.

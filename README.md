# J.A.R.V.I.S — 나만의 Windows 음성 AI 비서

화면 오른쪽 아래 구석에 **홀로그램 HUD**로 떠 있는 개인 비서입니다.
“자비스”라고 부르고 말로 시키면 Claude가 알아듣고 PC를 직접 조작합니다.

```
“자비스, 유튜브에서 아이유 노래 틀어줘”
“자비스, 메모장 열고 오늘 할 일 목록 써줘”
“자비스, 지금 화면에 있는 에러가 뭐야?”
“자비스, 볼륨 30으로 하고 10분 뒤에 알려줘”
“자비스, 구글 클래스룸에서 경제 탭 들어가 줘”
```

## 설치 & 실행

1. `setup.bat` 더블클릭 → 필요한 패키지 설치 (처음 한 번)
2. `start_jarvis.bat` 더블클릭 → 오른쪽 아래에 HUD가 나타납니다

### AI 연결 방식 (⚙ 설정 → AI CONNECTION)
- **Claude Pro 계정 (기본, 추가 비용 없음)**: 이 PC에 설치된 Claude Code의 로그인을 그대로 씁니다.
  사용량은 Pro 한도에서 차감되고, 대답이 API보다 몇 초 느립니다(첫 질문 약 8초, 이어지는 질문 약 3초).
  로그인이 안 되어 있다면 터미널에서 `claude` 를 한 번 실행해 Pro 계정으로 로그인하세요.
- **Claude API 키**: console.anthropic.com 에서 발급한 키를 입력. 쓴 만큼 과금되지만 더 빠릅니다.
- **로컬 전용**: Claude를 전혀 쓰지 않습니다(토큰 0). 아래 기본 명령만 처리합니다.

### 로컬 우선 (기본 켜짐) — 토큰 절약
자주 쓰는 짧은 명령은 Claude 없이 자비스가 직접, 1초 안팎으로 처리합니다.

| 종류 | 예시 |
|---|---|
| 앱 | “메모장 열어줘”, “크롬 켜”, “카톡 닫아줘” |
| 볼륨·음악 | “볼륨 30으로”, “소리 키워줘”, “음소거”, “다음 곡”, “노래 일시정지” |
| 유튜브·검색 | “유튜브에서 아이유 밤편지 틀어줘”, “아이유 노래 틀어줘”, “네이버에서 맛집 검색” |
| 정보 | “몇 시야”, “오늘 며칠이야”, “날씨 어때”, “부산 날씨”, “컴퓨터 상태 어때”, “볼륨 몇이야” |
| 화면 밝기 | “화면 밝기 50으로”, “화면 좀 어둡게”, “밝기 올려줘” (노트북 화면. 외장 모니터는 지원 안 될 수 있음) |
| 기타 | “5분 뒤에 알려줘”, “타이머 1시간 30분”, “다운로드 폴더 열어줘”, “바탕화면 보여줘”, “화면 잠가줘”, “스크린샷 찍어줘” |

### 로컬 AI (기본 켜짐) — 말을 바꿔 해도 토큰 0
위 표와 문장이 달라도 PC 안의 작은 AI(Ollama + Qwen 2.5 1.5B, 약 1GB)가 뜻을 알아듣고 같은 기본 명령으로 처리합니다.
“좀 시끄럽네” → 볼륨 내려, “크롬 좀 띄워 줄래” → 크롬 열어, “계란 7분 삶을 거야” → 7분 타이머. 판단에 약 1초 걸립니다.

- 로컬 AI는 위 표의 기본 명령으로만 바꿀 수 있습니다. 전원 끄기, PowerShell, 파일 작업, 대화는 할 수 없고 Claude에게 넘깁니다.
- 모델이 말에 없는 앱 이름이나 검색어를 지어내면 실행하지 않습니다. 볼륨을 키울지 줄일지는 말에 들어 있는 단서로 정합니다.
- 테스트 문장 37개 기준으로 31개를 맞혔고, 5개는 Claude에게 넘겼으며, 1개(“방금 노래 다시” → 이전 곡 대신 다시 재생)는 틀렸습니다.
- Ollama가 꺼져 있거나 모델이 없으면 조용히 건너뜁니다. 설정 → “로컬 AI”에서 끄거나 3B 모델로 바꿀 수 있습니다
  (이 PC에서는 3B가 두 배 느리고 정확도도 더 낮았습니다).

여러 동작이 섞인 명령(“메모장 열고 할 일 써줘”), 일반 질문·대화, 화면 분석, 내일 날씨, PC 종료 같은 요청은 Claude가 처리합니다.
로컬 처리 중 앱을 못 찾는 등 실패하면 Claude가 다시 시도합니다. 설정의 “로컬 우선” 스위치로 끌 수 있습니다.

트레이 아이콘 우클릭 → **Windows 시작 시 자동 실행**을 켜면 부팅할 때마다 자동으로 뜹니다.

> API 키가 없어도 “메모장 열어”, “볼륨 50”, “몇 시야” 같은 기본 명령은 동작합니다.

## 부르는 법

| 방법 | 동작 |
|---|---|
| “자비스” + 명령 | 호출어 상시 대기 (마이크 버튼으로 켜고 끔) |
| “자비스” 만 말하기 | 띵 소리 후 다음 말을 명령으로 받음 |
| `Ctrl + Alt + J` | 어디서든 바로 듣기 시작 (설정에서 변경 가능). 다른 앱이 이미 쓰고 있으면 `Ctrl+Alt+Shift+J` 등 대체 조합으로 자동 전환하고 HUD에 알려 줍니다 |
| 코어 클릭 | 듣기 시작 / 말하는 중이면 끊기 |
| 아래 입력창 | 글자로 명령 |

대답이 끝난 뒤 약 7초 동안은 호출어 없이 바로 이어서 말할 수 있습니다.
처리 중에 “취소”라고 말하면 작업을 멈춥니다.

## 목소리로 사람 구분 (화자 인식)

음높이(주파수)만 보면 같은 성별끼리는 거의 구분이 안 되므로, 발화를 192차원 “목소리 지문”(화자 임베딩)으로
바꿔 비교합니다. 음색·포먼트·발성 습관까지 반영되며 PC 안에서만 계산합니다 (3D-Speaker CAM++ 모델, 약 28MB,
처음 쓸 때 자동 다운로드).

| 기능 | 동작 |
|---|---|
| 세션 잠금 (기본 켬) | “자비스”라고 부른 사람의 목소리를 기억해, 이어지는 명령·승인·취소는 같은 사람 말만 받습니다. 대기 상태로 돌아가면 초기화되고, 다른 사람이 “자비스”라고 부르면 그 사람이 새 주인이 됩니다 |
| 주인 등록 | ⚙ 설정 → VOICE ID → **목소리 등록** (또는 트레이 메뉴). 화면의 문장 5개를 읽으면 끝나고, 이후에는 등록된 목소리에만 반응합니다 |

- 무시된 말은 HUD에 “목소리가 아니라서 무시했습니다 (유사도 0.23)”처럼 표시됩니다.
- **판별 엄격도** (기본 0.40): 본인 명령이 자주 무시되면 낮추고, 다른 사람 말에 반응하면 높이세요.
  `data/jarvis.log` 에 매번 유사도가 기록되니 참고해서 조정하면 됩니다.
- “네”처럼 0.5초도 안 되는 짧은 말은 판별이 어려워, 주인 전용 모드에서는 “승인”처럼 조금 길게 말하거나 버튼을 누르세요.
- “자비스” 한 마디보다 “자비스, 음악 틀어 줘”처럼 이어서 말할 때 더 정확합니다.
- 두 사람이 동시에 말하면 한 덩어리로 들려 판정이 흔들릴 수 있습니다.
- 보안 수단은 아닙니다. 녹음 재생이나 음성 복제로 속일 수 있으니 위험 명령 확인 창은 그대로 쓰세요.

## 음성 인식 (오프라인 + Google)

PC 안에서 돌아가는 오프라인 음성 인식(SenseVoice, 약 230MB, 처음 쓸 때 자동 다운로드)과 Google 웹 인식을 함께 씁니다.
⚙ 설정 → SPEECH RECOGNITION 에서 고릅니다.

| 방식 | 동작 |
|---|---|
| **자동 (기본)** | “자비스”를 기다리는 동안은 **PC 안에서만** 듣습니다. 호출어가 들렸을 때만 그 한 문장을 Google로 보내 정확하게 받아 적고, 대화 중에는 Google을 씁니다. 주변 대화는 밖으로 나가지 않고, 인터넷이 끊기면 오프라인 인식으로 계속 알아듣습니다 |
| 오프라인 전용 | 소리가 PC 밖으로 전혀 나가지 않습니다. 조금 덜 정확합니다 |
| Google 전용 | 예전 방식. 가장 정확하지만 인터넷이 필요하고 대기 중 말소리도 Google로 보냅니다 |

이 PC에서 명령 문장 60개(목소리 3종)로 시험한 결과: Google은 글자 오류율 0%, 약 0.6초 / 오프라인은 오류율 6.5%, 약 0.1초.
오프라인 인식이 “열어 줘”를 “열어져”로 적는 식의 버릇은 로컬 명령 처리기가 바로잡습니다.

## 화면 조작 (사이트·앱 안에서 클릭)

“구글 클래스룸에서 경제 탭 들어가 줘”, “설정에서 블루투스 눌러 줘”처럼 **창이나 웹 페이지 안의 버튼·탭·링크를 직접 누릅니다.**
Windows UI 자동화로 창 안의 요소 목록을 읽기 때문에, 로그인된 내 크롬·엣지를 그대로 쓰고 일반 앱에서도 동작합니다.
Claude가 “읽기 → 누르기 → 바뀐 화면 확인”을 반복해 목적지까지 갑니다 (Pro 계정·API 키 모드).

- 목록에서 못 찾는 요소(게임, 그림 위 버튼 등)는 화면을 보고 좌표로 클릭합니다.
- 이름에 **결제·구매·주문·송금·삭제·전송·보내기·제출·게시** 같은 말이 들어간 버튼은 누르기 전에 승인 카드가 뜹니다.
- 로그인 화면이 나오면 비밀번호를 입력하지 않고 직접 로그인해 달라고 요청합니다.

## 할 수 있는 일 (도구 30종 + 웹 검색)

- **앱**: 실행(시작 메뉴 전체 검색 — 한글 이름 OK) · 종료 · 창 전환 · 열린 창 목록
- **창/키보드**: 바탕화면 보기, 최대화/최소화, 좌우 분할, 텍스트 입력(한글 지원), 단축키 입력
- **웹**: 링크 열기, 구글/네이버/유튜브 검색, 유튜브 첫 영상 바로 재생, Claude 웹 검색으로 최신 정보 답변
- **미디어**: 재생/일시정지/다음 곡, 볼륨 설정/음소거
- **화면**: 화면을 보고 질문에 답하기(Claude 비전), 스크린샷 저장, 창·웹 페이지 안의 버튼/링크/탭 읽기·클릭, 스크롤, 화면 밝기
- **파일**: 폴더 열기, 파일 이름 검색, 파일 열기
- **시스템**: CPU/메모리/디스크/배터리 진단, 잠금·절전·재시작·종료, PowerShell 명령
- **기타**: 타이머/알림, 날씨, 클립보드 읽기/쓰기, “기억해” 장기 기억

### 안전장치
PowerShell 실행, 절전/재시작/종료, 실행 파일 열기, 결제·삭제·전송 같은 버튼 클릭은 HUD에 **승인 카드**가 뜨고,
버튼을 누르거나 “승인” / “취소”라고 말해야 실행됩니다 (45초 무응답 시 자동 거부).
앱 종료는 강제 종료가 아니라 정상 닫기 요청이라 저장 안 한 문서는 앱이 물어봅니다.

## 구성

```
main.py              실행 진입점 (트레이, 단일 실행 보장)
jarvis/app.py        오케스트레이터: 음성 → 두뇌 → 행동 → 음성, 상태 관리
jarvis/listener.py   마이크 입력, 음성 구간 감지(VAD), 인식 엔진 선택(오프라인/Google)
jarvis/local_stt.py  오프라인 음성 인식 (SenseVoice, sherpa-onnx)
jarvis/voiceid.py    화자 인식: 목소리 지문, 주인 등록, 세션 잠금
jarvis/speech.py     Edge 신경망 음성 합성(인준) → 실패 시 Windows SAPI, 재생
jarvis/brain.py      두뇌: 로컬 우선 → Pro 계정(Claude Code 호출) / API 에이전트 루프
jarvis/local_router.py 로컬 명령 처리기 (토큰 없이 자주 쓰는 명령 즉시 처리)
jarvis/local_ai.py   로컬 AI: Ollama 작은 모델이 바꿔 말한 명령을 표준 명령으로 번역
jarvis/toolserver.py Pro 모드에서 Claude Code가 PC 도구를 쓰도록 여는 로컬 서버 (127.0.0.1 전용, 토큰 인증)
jarvis/mcp_bridge.py Claude Code ↔ 자비스 도구 연결용 MCP 서버
jarvis/tools.py      PC 제어 도구 모음과 도구 스키마
jarvis/uia.py        화면 조작: Windows UI 자동화로 창·웹 페이지 안의 요소 읽기/클릭
jarvis/winutil.py    키 입력, 창 제어, 클립보드 등 Win32 유틸
jarvis/hotkey.py     전역 단축키
ui/*.qml             홀로그램 HUD (Qt Quick, GPU 렌더링)
ui/Emblem.qml        J.A.R.V.I.S 엠블럼 코어 — 원본 이미지를 구성 요소별로 벡터로 다시 그림 (축소·전체 모드 공용)
ui/assets/           엠블럼 원본 이미지 (디자인 참고용, 화면에는 쓰지 않음)
tests/               회귀 테스트 (python -m pytest)
data/                설정(config.json), 기억(memory.json), 목소리 지문(voice_profile.json), 로그 — 공유 금지
```

## 설정 (HUD ⚙ 또는 `data/config.json`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| AI 연결 | Pro 계정 | Pro 계정(무료) / API 키(과금) / 로컬 전용(토큰 0) |
| 로컬 우선 | 켬 | 기본 명령은 Claude 없이 즉시 처리 |
| 모델 | Pro: Haiku · API: Opus 5.5 | Pro에서 Opus는 한도를 빨리 소모합니다 |
| 응답 깊이 | low | 음성 비서는 low가 가장 빠름 |
| 음성 | 인준(남성) | 현수(남성), 선희(여성) |
| 호칭 | 주인님 | 자비스가 부르는 이름 |
| 마이크 감도 | 1.0 | 잘 못 알아들으면 올리고, 잡음에 반응하면 내리세요 |
| 음성 인식 | 자동 | 자동(대기 중 오프라인) / 오프라인 전용 / Google 전용 |
| 소음 환경 모드 | 켬 | 음성 감지 AI + 소음 제거 AI(오프라인, 약 1.2MB)로 시끄러운 곳에서도 작은 목소리를 잡습니다. TV·대화 소리 속에서는 한계가 있어요 |
| 세션 잠금 | 켬 | 부른 사람의 목소리만 이어서 인식 |
| 주인 목소리에만 반응 | 끔 (등록하면 켜짐) | 등록된 목소리가 아니면 호출어도 무시 |
| 판별 엄격도 | 0.40 | 0.25(느슨함) ~ 0.60(엄격함) |
| 위험 명령 자동 승인 | 끔 | 켜면 확인 없이 실행 (권장하지 않음) |

`config.json` 의 `wake_words` 에 호출어를 추가할 수 있고, `position` 을 `top-right` 로 바꾸면 오른쪽 위에 뜹니다.

## 비용과 개인정보

- Pro 계정 모드는 추가 요금이 없고 Pro 사용 한도만 차감됩니다. API 키 모드는 명령마다 사용량 요금이 듭니다. 대화는 10분 쉬면 새로 시작합니다.
- 음성 인식 ‘자동’(기본)에서는 호출어 대기 중 말소리를 PC 안에서만 처리하고, “자비스”가 들린 문장과 이어지는 대화만 Google 음성 인식 서버로 보냅니다.
  ‘오프라인 전용’을 고르면 말소리가 전혀 밖으로 나가지 않습니다. 오프라인 모델이 준비되기 전(첫 다운로드 중)에는 Google로 인식합니다.
- 화면 분석을 요청할 때만 화면 캡처가 Claude로 전송됩니다 (HUD 자신은 캡처에서 제외).
- 목소리 지문(`data/voice_profile.json`)과 화자 인식 모델(`data/models/`)은 PC에만 있고 외부로 보내지 않습니다. 설정에서 삭제할 수 있습니다.

## 문제 해결

- 로그: `data/jarvis.log` (트레이 메뉴 → 데이터 폴더 열기)
- 마이크가 안 될 때: Windows 설정 → 개인 정보 → 마이크 → 데스크톱 앱 마이크 액세스 허용
- 단축키 등록 실패: 다른 프로그램이 같은 조합을 쓰는 중 → 설정에서 다른 조합으로 변경
- 콘솔에서 실행해 오류 보기: `python main.py` (옵션: `--no-mic`, `--no-greet`)
- 화면 조작이 버튼을 못 찾을 때: 크롬·엣지는 처음 읽을 때 1초쯤 걸립니다. 그래도 안 되면 “화면 보고 눌러 줘”처럼 말하면 화면을 보고 클릭합니다.
